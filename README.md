# 📚 DSA Repository

This repository contains implementations of **Data Structures and Algorithms (DSA)** in multiple programming languages: **C, C++, Python, and Java** of https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z. It is designed for practice, learning, and quick reference.

---

## 📁 Folder Structure

```
A2ZDSA/
│
├── C/          # C language implementations
├── CPP/        # C++ implementations
├── Python/     # Python implementations
├── JAVA/       # Java implementations
```

Each folder contains programs related to common DSA topics such as:

* Arrays
* Linked Lists
* Stacks & Queues
* Trees
* Graphs
* Sorting & Searching
* Recursion & Backtracking
* Dynamic Programming

---

## 📥 Clone Repository

```bash
git clone https://github.com/abhishek0628/A2ZDSA.git
cd A2ZDSA
```

## 🚀 How to Use

### C Programs

```bash
gcc filename.c -o output
./output
```

### C++ Programs

```bash
g++ filename.cpp -o output
./output
```

### Python Programs

```bash
python filename.py
```

### Java Programs

```bash
javac filename.java
java filename
```
